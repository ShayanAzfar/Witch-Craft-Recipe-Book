# Witch Craft Recipe Book
## Learn new recipe & rituals from the witch!

## Desciption
### Its a simple 3d project and illustration of a recipe witch craft recipe book! Made entirely from Vanilla HTML CSS and JS.

## How to Read The Book?
### By clicking on the book page cover, it will open the first page of the book, after that you can continue reading more pages by clicking on the current page, if you want to close the book or start reading from the page 1 you have to click on the back cover of the book.
